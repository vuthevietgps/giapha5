## Status semantics

- `PASSED`: executed and verified in the latest run
- `FAILED -> FIXED -> PASSED`: real failure was observed, fix was made, and rerun passed
- `GAP FOUND -> FIXED -> PASSED`: production risk was identified in code or contract review, regression was added, and the new regression now passes
- `OPEN RISK`: known risk with no execution proof yet
- `NOT RUN`: planned but not executed in the recorded run
- `BLOCKED`: execution could not proceed because of environment or dependency limits
