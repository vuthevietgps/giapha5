Hướng dẫn cài đặt

  1. Tải file APK về máy (nhấn nút ở trên).
  2. Mở file APK và chọn Cài đặt.
  3. Nếu có cảnh báo "Nguồn không xác định/Unknown sources":
    • Vào Cài đặt → Bảo mật
    • Bật "Cho phép cài đặt từ nguồn không xác định"
    • Quay lại và cài đặt tiếp
  4. Mở ứng dụng và cấp quyền Camera và Thông báo khi được hỏi.

Yêu cầu hệ thống

  • Android 7.0 (API level 24) trở lên
  • 50MB dung lượng trống
  • Kết nối Internet

apple Cài đặt trên iPhone/iPad

download Tải từ TestFlight (Beta)

TestFlight là cách tốt nhất để cài app iOS trong giai đoạn thử nghiệm:

  1. Cài đặt app TestFlight từ App Store (miễn phí)
  2. Nhấn vào link mời beta (sẽ được admin gửi qua email/Zalo)
  3. Chấp nhận lời mời và cài đặt app
  4. App sẽ tự động cập nhật khi có phiên bản mới

✅ Đây là phương thức được Apple khuyến nghị

store Tải từ App Store (Chính thức)

Ứng dụng sẽ có mặt trên App Store sau khi hoàn tất quy trình phê duyệt của Apple.

info Hiện tại đang trong giai đoạn phát triển

developer_mode Cài đặt Ad Hoc (Nâng cao)

Ad Hoc distribution - cho tối đa 100 thiết bị test:

  1. Gửi UDID của thiết bị cho admin (Cài đặt → Chung → Giới thiệu → UDID)
  2. Admin sẽ thêm UDID vào Developer Portal
  3. Nhận file IPA và cài qua iTunes/Finder hoặc dịch vụ OTA
download Tải file IPA (nếu có)

Yêu cầu hệ thống

  • iOS 13.0 trở lên
  • iPhone 6s hoặc mới hơn / iPad Air 2 hoặc mới hơn
  • 50MB dung lượng trống
  • Kết nối Internet

Build app iOS từ source code

Nếu bạn là developer và muốn tự build app iOS:

  • Cần có máy Mac với macOS và Xcode
  • Apple Developer Account ($99/năm để publish)
  • Xem hướng dẫn chi tiết trong file IOS_BUILD_GUIDE.md

Lưu ý: Không thể build iOS app trên Windows. Nếu không có Mac, có thể dùng dịch vụ Mac cloud hoặc TestFlight.

Kết nối đến máy chủ

Ứng dụng kết nối đến API tại: {{ apiUrl }}

Nếu bạn tự cài đặt server, hãy đảm bảo:

  • Server chạy và truy cập được từ mạng của điện thoại
  • Nếu dùng HTTP (không HTTPS), cần cấu hình đặc biệt:
    • Android: Đã cấu hình sẵn cho phép HTTP trong network_security_config.xml
    • iOS: Cần thêm exception trong Info.plist
  • Khuyến nghị dùng HTTPS cho bảo mật và tính năng camera ổn định

Triển khai file cài đặt
