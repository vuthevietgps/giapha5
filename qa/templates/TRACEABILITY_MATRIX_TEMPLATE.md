# Traceability Matrix Template

## Hướng dẫn

- Mỗi dòng đại diện cho một yêu cầu hoặc rủi ro cần kiểm soát.
- `Nguồn yêu cầu` có thể là ticket, backlog, release note, README nghiệp vụ hoặc defect.
- `Coverage status` phản ánh mức sẵn sàng test hiện tại, không phải cảm tính.

| Requirement ID | Mô tả yêu cầu/rủi ro | Nguồn yêu cầu | Module | Test Case ID | Test Run/Test Result mới nhất | Defect liên quan | Owner | Coverage status |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `RQ-AREA-001` |  |  |  | `TC-AREA-001` |  |  |  | Not Covered / Planned / In Progress / Covered / Blocked |
