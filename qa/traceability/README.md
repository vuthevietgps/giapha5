# Traceability

Thư mục này dùng để map:

- yêu cầu hoặc rủi ro;
- testcase;
- test run/test result;
- defect liên quan;
- trạng thái coverage hiện tại.

`TRACEABILITY_MATRIX.md` đang là bản seed mức tổng quan. Khi team có thêm ticket hoặc release scope cụ thể, cập nhật từ file này hoặc copy ra file riêng theo release.
