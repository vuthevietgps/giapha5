# Reports

Thư mục này lưu tài liệu tổng hợp dùng để giao tiếp tiến độ và quyết định chất lượng.

## Cách dùng

- `daily/`: báo cáo QA hằng ngày theo template daily report.
- `releases/`: bug summary, sign-off và tài liệu tổng hợp ở mức release/cycle.

## Naming gợi ý

- Daily report: `YYYY-MM-DD-qa-daily-report.md`
- Bug summary: `<release>-bug-summary.md`
- Sign-off: `<release>-qa-signoff.md`
