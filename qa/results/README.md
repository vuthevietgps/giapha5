# Results

Thư mục này lưu kết quả thực thi và bằng chứng test.

## Cách dùng

- `executions/`: file test run hoặc test result đã được điền thực tế theo từng phiên chạy.
- `evidence/`: ảnh chụp màn hình, video, log, file export mẫu phục vụ xác minh kết quả hoặc defect.

## Nguyên tắc

- Không ghi đè evidence cũ nếu nó còn giá trị điều tra.
- Tên file nên map về testcase, defect hoặc test run để truy vết nhanh.
